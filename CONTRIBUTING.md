# Como Contribuir

Obrigado pelo interesse no projeto!

## Encontrou um bug ou erro?

Abra uma [Issue](../../issues) descrevendo o problema. Tente incluir:

- O que você fez
- O que esperava acontecer
- O que aconteceu de fato
- Versão do VS Code e do Node.js

## Discussões

As Issues também estão abertas para sugestões e dúvidas gerais — fique à vontade para abrir uma conversa.
